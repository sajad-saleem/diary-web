# Firebase Diary App

A personal diary app using **Firebase Auth + Firestore**, hosted on **GitHub Pages**.

## 🚀 Features
- Register/Login with Firebase Authentication
- Add/Delete/Search diary entries
- Private entries per user
- Secure Firestore rules
- Hosted free on GitHub Pages

## 📂 Setup
1. Create Firebase Project → Enable **Auth (Email/Password)** + **Firestore**.
2. Copy your Firebase config into `firebase.js`.
3. Deploy on GitHub Pages:
   - Push this folder to a new repo
   - Settings → Pages → Deploy from `main` branch → `/ (root)`
